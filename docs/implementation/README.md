## Quy tắc

1. Mỗi phase có 1 file tracking riêng ghi chi tiết tasks đã làm, đang làm, issues gặp phải.
2. Cập nhật README.md khi chuyển phase.
3. Mỗi phase phải pass kiểm thử trước khi chuyển sang phase tiếp theo.
4. Ghi lại mọi quyết định kỹ thuật phát sinh trong quá trình code.
